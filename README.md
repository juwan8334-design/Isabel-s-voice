# Isabel's Voice PWA — 시제품

## 포함된 기능
- 모바일·PC 반응형 메인 화면
- 건의 게시판 예시 및 공감 버튼
- 이 기기 안에서만 동작하는 건의 작성 데모
- 투표·이벤트 화면
- PWA manifest 및 service worker

## 현재 제한
이 버전은 프론트엔드 시제품입니다. 데이터는 여러 학생 사이에서 공유되지 않습니다.
실제 학번·이름을 입력하거나 실제 학교 투표에 사용하지 마세요.
관리자 로그인과 실제 투표 제출은 보안상 비활성화되어 있습니다.

## 실행
`index.html`을 브라우저에서 열어 화면을 확인할 수 있습니다.
PWA 설치와 오프라인 캐시는 HTTPS로 제공되는 웹 호스팅에서 동작합니다.

## 다음 단계
전교생 공개 운영 전 학교 승인, 개인정보 처리 기준, 서버 측 인증·권한 관리, 중복 투표 방지, 백업 및 삭제 정책을 확정해야 합니다.
정적 호스팅만으로는 공용 게시판/투표 데이터 저장이 불가능합니다.
